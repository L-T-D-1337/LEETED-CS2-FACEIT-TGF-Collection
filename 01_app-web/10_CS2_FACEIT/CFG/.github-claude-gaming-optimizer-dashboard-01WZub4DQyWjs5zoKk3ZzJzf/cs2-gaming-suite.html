📚 Optimization Guide

// DkZ Windows Gaming Optimization Guide

=== SCHRITT 1: WINDOWS GRUNDEINSTELLUNGEN ===
1. Windows Update durchführen
2. Grafiktreiber aktualisieren (NVIDIA/AMD)
3. Unnötige Autostart-Programme deaktivieren
4. Windows Defender Ausnahmen für CS2 hinzufügen

=== SCHRITT 2: ENERGIEEINSTELLUNGEN ===
• Systemsteuerung > Energieoptionen > Höchstleistung
• PCI Express > Link State Power Management: Aus
• Prozessorenergieverwaltung > Minimaler Prozessorzustand: 100%
• USB-Einstellungen > Selektives USB-Energiesparen: Deaktiviert

=== SCHRITT 3: NVIDIA CONTROL PANEL ===
Manage 3D Settings > Program Settings > CS2:
• Power Management Mode: Prefer Maximum Performance
• Low Latency Mode: Ultra
• Max Frame Rate: Off
• Texture Filtering - Quality: High Performance
• Threaded Optimization: On
• Vertical Sync: Off
• Shader Cache Size: Unlimited

=== SCHRITT 4: AMD RADEON SETTINGS ===
Gaming > Global Settings:
• Anti-Lag: Enabled
• Radeon Boost: Enabled
• Radeon Chill: Disabled
• Radeon Image Sharpening: Enabled (80%)
• Wait for Vertical Refresh: Always Off
• Texture Filtering Quality: Performance

=== SCHRITT 5: NETZWERK OPTIMIERUNG ===
CMD als Administrator:
  netsh int tcp set global autotuninglevel=normal
  netsh int tcp set global chimney=enabled
  netsh int tcp set global dca=enabled
  netsh int tcp set global netdma=enabled
  netsh int tcp set global ecncapability=disabled
  netsh int tcp set heuristics disabled

=== SCHRITT 6: WINDOWS GAME MODE ===
Einstellungen > Gaming:
• Game Mode: Ein
• Game Bar: Aus (oder nach Präferenz)
• Captures: Hintergrundaufnahme: Aus
• Broadcasting: Aus

=== SCHRITT 7: VISUELLE EFFEKTE ===
Systemsteuerung > System > Erweiterte Systemeinstellungen
> Leistung > Einstellungen > Für optimale Leistung anpassen
Behalte nur:
  ☑ Symbole statt Miniaturansichten anzeigen
  ☑ Schriftarten mit Kantenglättung

=== SCHRITT 8: STARTUP OPTIMIERUNG ===
Task-Manager > Autostart:
Deaktiviere unnötige Programme:
• Adobe Creative Cloud
• Spotify
• Discord (falls nicht benötigt)
• Microsoft OneDrive
• Diverse Update-Services

=== SCHRITT 9: HINTERGRUND-APPS ===
Einstellungen > Datenschutz > Hintergrund-Apps
Deaktiviere alle außer:
• Windows Security
• Store (optional)

=== SCHRITT 10: NVIDIA REFLEX (falls verfügbar) ===
In CS2 Video-Einstellungen:
• NVIDIA Reflex Low Latency: Enabled + Boost

=== PERFORMANCE MONITORING ===
Empfohlene Tools:
• MSI Afterburner (GPU Monitoring & OC)
• HWiNFO64 (Detaillierte System-Info)
• LatencyMon (DPC Latency Checker)
• ThrottleStop (CPU Undervolting)
• Process Lasso (Automatische Process Priority)

=== EXPECTED RESULTS ===
Nach allen Optimierungen:
✅ +15-30% FPS Boost
✅ -5-10ms Input Lag Reduktion
✅ Stabilere Frametimes
✅ Weniger Stuttering
✅ Schnellere Ladezeiten
